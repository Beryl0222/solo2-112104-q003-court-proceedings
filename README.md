# 庭审笔录中的争点、引述与证据引用整理

本项目整理法律援助团队需要把分段录入的庭审笔录整理成复核清单。书记员更正姓名或引述对象时，原来的争点引用可能仍挂在错误当事人名下；若直接生成结论性摘要，复核人员无法区分证人陈述、律师主张和法庭已经确认的事实。

演练资料位于 `data/court.json`，内容为合成记录，保留不同来源的原始表述和修订关系。项目环境使用 Python 3.11 标准库。

当前资料检查入口为 `python3 -m unittest discover -s tests -v`。检查仅确认 JSON 文件可以读取、记录字段完整且每条原文存在，不会生成业务判断。尚无面向使用者的业务命令。
